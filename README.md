Ao analisar os perfis de desenvolvedores profissionais no GitHub, identifiquei algumas práticas importantes para a construção de um portfólio técnico. Um dos padrões mais comuns foi a utilização de apresentações organizadas, destacando as habilidades, tecnologias e áreas de interesse de cada profissional. Também observei que os repositórios fixados são escolhidos estrategicamente para apresentar os projetos mais relevantes. Outro ponto importante foi a qualidade da documentação, com arquivos README que explicam os objetivos dos projetos, as tecnologias utilizadas e as instruções de execução. Além disso, a organização dos arquivos, a presença de licenças e a utilização do .gitignore demonstram preocupação com boas práticas de programação. A atividade dos desenvolvedores e suas contribuições para projetos Open Source também mostram a importância da participação na comunidade de tecnologia. Com base nessas observações, pretendo aplicar essas práticas ao meu próprio GitHub, utilizando uma apresentação clara e objetiva. Também buscarei organizar meus repositórios com nomes descritivos e documentar melhor meus projetos. Como estudante de Engenharia de Software, pretendo destacar as tecnologias que estou aprendendo, como C, Python e HTML, além dos trabalhos desenvolvidos durante a graduação. Meu principal objetivo é utilizar o GitHub como um portfólio que demonstre minha evolução e meu desenvolvimento como programador.
